# GMA Auth Module

This repository owns the optional GMA Auth module: member registration/login, refresh tokens, JWT integration, admin member management, provider-split persistence, and auth integration events.

It is consumed by source-first applications and by the `gma-skeleton` composition repository as a Git submodule under `gma/modules/auth`.

Useful entry points:

- `Gma.Modules.Auth.slnx`
- `docs/README.md`
